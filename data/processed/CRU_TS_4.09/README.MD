# Processed CRU TS 4.09 Data

This folder contains the final processed CRU TS datasets used in the analyses.

For sites `YAK` and `TAY`, precipitation (`pre`) and vapour pressure deficit (`vpd`) values
were replaced with instrumental meteorological station data from `data/processed/climate`
(station `Chokurdakh` for `YAK` and station `Khatanga` for `TAY`) rather than CRU TS gridded
values, because CRU TS grid data for these sites showed strong disagreement with
instrumental observations.
