# Data Directory

This folder stores source data and derived datasets at different stages of processing.

- `external`: Third-party data that does not belong to this project, downloaded from open sources.
- `raw`: Original raw input data.
- `transformed`: Data from `raw` that has been cleaned, transformed, or otherwise pre-processed.
- `processed`: Final datasets produced from raw and transformed data; these are the datasets used in the analyses and publications.
